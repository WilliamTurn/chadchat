# Performance, mobile-platform craft, and trust (canon 06)

Owning file: `docs/ux-canon/06-performance-mobile-trust.md` (175 principles). **[M]** mechanical, **[J]** judgment. Cite numbers (e.g. `// canon 06 §90`). Judge at the 75th percentile on mid-range mobile, throttled — not your dev machine (§4).

## Hard-rule digest

**A. Core Web Vitals & budgets** — 1 [M] LCP <2.5s (p75 field). 2 [M] INP <200ms (p75). 3 [M] CLS <0.1. 4 [M] judge at p75 on mid-range mobile, throttled. 5 [M] TTFB <~800ms. 6 [M] above-the-fold loads first; third-party never blocks first paint. 7 [M] enforce a performance budget in CI. 8 [M] field-monitor vitals continuously (RUM). 9 [M] reserve space for everything that loads late. 10 [M] never insert content above what the user is reading. 11 [M] break long main-thread tasks (<~50ms). 12 [M] first screen renders without waiting for client JS.

**B. Perceived performance** — 13 [M] acknowledge every input <100ms even if work is longer. 14 [M] >1s progress indicator, >10s bar + escape. 15 [J] optimistic UI for near-always-success actions. 16 [M] delay spinners ~150–300ms, keep ≥300–500ms. 17 [M] skeletons matching real layout, not generic spinners, for content loads. 18 [J] one coordinated loading experience per view. 19 [J] front-load useful content during waits (SWR). 20 [J] make the start fast even if the total is the same. 21 [M] never freeze the UI during background work. 22 [M] show real numbers for long transfers. 23 [M] debounce expensive reactions to typing, never the echo of typing. 24 [M] pressed state instant + physical (touch-down).

**C. Instant navigation & prefetch** — 25 [M] in-app navigations feel instant (<100–300ms), never a white-page reload. 26 [M] prefetch likely next destinations (viewport/intent). 27 [M] prefetch politely (respect Save-Data/metered, cap). 28 [M] back instant + restores exactly (bfcache-eligible, no `unload`). 29 [M] cache aggressively (immutable hashed assets). 30 [M] never block navigation on analytics. 31 [M] preserve state in the URL. 32 [J] view transitions for continuity, kept fast.

**D. Images & media perf** — 33 [M] responsive images (`srcset`/`sizes`) sized to the slot. 34 [M] modern formats (AVIF/WebP) with fallbacks. 35 [M] lazy-load below-fold, NEVER the LCP/hero image. 36 [M] every image has intrinsic dimensions/aspect-ratio box. 37 [J] placeholder (blur-up/color/skeleton) while loading. 38 [M] video never autoplays with sound; heavy media loads only when needed. 39 [M] compress + cap image quality (q≈70–85), audit weight. 40 [M] CDN-delivered, cache-immutable media.

**E. Fonts** — 41 [M] text never invisible while fonts load (`font-display: swap`/`optional`). 42 [M] metric-matched fallback to kill swap reflow. 43 [M] self-host + preload critical + subset (WOFF2). 44 [M] cap font count (~2 families), variable fonts for weights. 45 [J] system font stacks are a legit zero-cost choice for chrome.

**F. Bundle & JS discipline** — 46 [M] ship the least JS; treat JS as the most expensive byte. 47 [M] code-split by route + interaction. 48 [M] audit/evict dependencies. 49 [M] third-party scripts deferred/worker, never render-blocking. 50 [M] tree-shake + dead-code-eliminate. 51 [M] compress everything (Brotli/gzip, minified). 52 [M] defer non-critical work to idle.

**G. Hydration / no flash** — 53 [M] no flash of wrong content ever (FOUC/auth/theme/lang). 54 [M] hydration must not eat input. 55 [M] server + client render match (zero mismatch). 56 [M] interactive elements never visible-but-dead. 57 [M] visually stable from first paint (no post-load re-layout). 58 [M] cookie banners/toasts/overlays never shift layout or steal focus on load. 59 [M] personalized/experiment content resolves before paint or degrades. 60 [J] progressive real content, not a full-screen splash.

**H. Animation & scroll perf** — 61 [M] animate only transform+opacity. 62 [M] hold frame rate on a mid-range phone. 63 [M] short animations (~150–300ms, micro <100ms). 64 [M] honor `prefers-reduced-motion` everywhere. 65 [J] never hijack/slow/re-ease native scroll. 66 [M] virtualize long lists. 67 [M] no scroll-linked effects on the main thread. 68 [J] animations interruptible, never block input.

**I. Memory & long-session** — 69 [M] survive a long session without degrading (profile leaks). 70 [M] unmount = clean up every listener/timer/observer/socket. 71 [M] cap in-memory caches + media retention. 72 [M] handle tab restore/discard gracefully. 73 [M] pause timers/polling/animation when hidden (Page Visibility).

**J. Viewport & mobile layout** — 74 [M] correct viewport meta, never `user-scalable=no`/`maximum-scale=1`. 75 [M] respect safe areas (`viewport-fit=cover` + `env(safe-area-inset-*)`). 76 [M] use dvh/svh/lvh; `100vh` is broken on mobile. 77 [M] zero horizontal overflow from 320px up. 78 [M] fluid layouts, not device-targeted. 79 [M] support landscape or consciously handle it; rotation never loses work. 80 [M] test real OS font scaling/display zoom. 81 [J] full-bleed edges account for OS gesture zones.

**K. Touch & thumb zone** — 82 [M] targets ≥44×44pt/48dp + ~8px spacing. 83 [J] primary actions in the thumb zone (bottom). 84 [M] gestures are accelerators, never the only path. 85 [J] distinguish tap/long-press/swipe zones. 86 [M] no hover-dependent functionality on touch. 87 [M] eliminate tap delays/double-firing (`touch-action: manipulation`). 88 [J] drag has generous handles, never fights scroll. 89 [J] design for interruption (persist continuously).

**L. Mobile keyboards** — 90 [M] text inputs ≥16px on iOS (else zoom). 91 [M] focused field never under the keyboard (VisualViewport). 92 [M] sticky bottom bars account for the open keyboard. 93 [M] declare the right keyboard (`inputmode`/`type`/`enterkeyhint`). 94 [M] `autocomplete` tokens + never block paste (`one-time-code`). 95 [M] disable autocorrect/autocap where they sabotage. 96 [M] keyboard dismiss is easy + never loses input. 97 [J] prefer platform pickers/steppers over freeform typing on mobile.

**M. Mobile-browser quirks** — 98 [M] verify `position: fixed` with keyboard/URL-bar/scroll; prefer `sticky`. 99 [M] control overscroll (`overscroll-behavior`) — no accidental pull-to-refresh/scroll-chaining. 100 [M] if you offer pull-to-refresh, follow the platform convention exactly. 101 [M] body scroll locks correctly under overlays; restore position on close. 102 [M] kill iOS tap flash/double-tap-zoom deliberately. 103 [M] keep momentum scrolling native. 104 [M] test real iOS Safari + Android Chrome, not emulation. 105 [M] verify critical flows in in-app browsers (webviews).

**N. PWA / installed app** — 106 [M] if installable, meet the full PWA baseline (manifest/maskable icons/theme/offline fallback). 107 [M] standalone = you provide back navigation everywhere. 108 [J] never spam install prompts; offer contextually. 109 [M] installed app works offline to a shell+message level. 110 [M] match OS (theme-color/status bar/splash/dark assets). 111 [M] sync state across installed app + browser identities.

**O. Device respect** — 112 [M] honor Save-Data/data-saver. 113 [M] set a low-end device budget + test on one (~$150 Android). 114 [M] don't burn background battery (push not poll, stop sensors). 115 [J] continuous GPU effects are budgeted, never ambient; pause when hidden. 116 [M] respect `prefers-reduced-*` as a family. 117 [M] degrade by capability (feature-detect), never block the browser. 118 [J] usable on flaky networks (offline-ish).

**P. Privacy UX & consent** — 119 [M] Decline is as easy/prominent as Accept. 120 [M] no pre-ticked boxes/consent by inertia. 121 [J] say what you collect + why, in plain language, at the moment it matters. 122 [J] ask permissions in context after value. 123 [M] pre-prompt before the one-shot system permission prompt. 124 [M] account deletion self-serve/findable/complete. 125 [M] data export available + usable. 126 [J] privacy defaults are the protective ones. 127 [J] don't ask for data you don't need. 128 [J] honest specific notice on terms/privacy changes.

**Q. Security UX** — 129 [M] never break password managers (real inputs, correct autocomplete, no paste block, login fields in initial DOM). 130 [M] support passkeys/WebAuthn with email/password fallback. 131 [M] password rules up front + live validation. 132 [M] show/hide password toggles. 133 [contested] OTP `one-time-code`/paste/auto-fill — auto-SUBMIT needs a house decision (tension with 05 §14.101); auto-advance is rejected. 134 [J] explain security friction. 135 [M] transparent controllable sessions (list devices, log-out-everywhere). 136 [M] session expiry never destroys work. 137 [M] errors don't leak but recovery doesn't punish. 138 [M] notify security-relevant events honestly. 139 [M] all over HTTPS, no mixed content, never train users to click through warnings.

**R. Payments trust** — 140 [J] the payment step looks/feels more secure than any other screen. 141 [M] show the full total (shipping/tax/fees) before asking for payment. 142 [M] standard card anatomy (single field, live formatting/brand, wallet options first). 143 [J] never ask for more payment data than needed + say how it's handled. 144 [M] state price/period/renewal unmissably before purchase. 145 [M] confirm every transaction on-screen + by receipt. 146 [J] refund/cancellation policies visible before purchase. 147 [M] payment errors never double-charge or leave ambiguity (idempotent + explicit "not charged"/"charged once").148 [M] guest checkout exists; account creation is a post-purchase offer.

**S. Anti-dark-pattern** — 149 [M] no confirm-shaming. 150 [M] no roach motels (leaving as easy as entering). 151 [M] honest urgency/scarcity only. 152 [M] no sneaking (nothing enters cart/subscription/consent without explicit action). 153 [M] no forced continuity without warning. 154 [J] no misdirection weighting on consequential choices. 155 [M] a dismissed prompt stays dismissed (no nagging loops). 156 [J] no obstruction of comparison/transparency. 157 [J] no trick wording/double negatives. 158 [M] no friend-spam/contact-harvesting under vague pretenses. 159 [M] ads are unmistakably ads. 160 [J] don't weaponize defaults against the user's known intent.

**T. Status honesty** — 161 [M] public status page linked from error states. 162 [J] report incidents honestly + promptly (acknowledge before diagnose). 163 [M] distinguish you're-offline / we're-down / in-between in-app. 164 [J] announce maintenance ahead + honor the window. 165 [J] degrade with a banner, not a lie. 166 [J] close the loop after a user-affecting failure.

**U. Resilience** — 167 [M] one component's crash never takes down the screen (error boundaries). 168 [M] every fetch has a failure plan (backoff + fallback + manual retry). 169 [J] core content works before/without JS where feasible. 170 [M] failed optional subsystems disappear gracefully. 171 [M] writes are never lost to a failure. 172 [M] retries are safe by design (idempotent + disabled resubmit). 173 [M] version skew doesn't strand users ("new version — refresh"). 174 [M] third-party outages are contained. 175 [M] feature flags/kill switches fail closed to a working experience.
