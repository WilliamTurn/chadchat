# Visual design, motion, and content (canon 04)

Owning file: `docs/ux-canon/04-visual-motion-content.md` (168 principles). **[M]** mechanical, **[J]** judgment. Cite numbers (e.g. `// canon 04 §127`). This domain composes UNDER the `app/globals.css` tokens (ds.css port pending — re-point on land) and the `/design-system` reference sheet — where a rule here conflicts with an approved token or owner decision, the token/decision wins (log it).

## Hard-rule digest

**1. Typography** — 1 [M] deliberate type scale, only its steps. 2 [M] body ≥16px. 3 [M] never below 12px, ever; labels 13px+ on phones (owner order, app/globals.css tokens). 4 [M] inputs ≥16px on mobile. 5 [M] line length 45–75ch. 6 [M] line-height scales inversely with size. 7 [J] tighten tracking on large display, never body. 8 [J] hierarchy from weight+color before size. 9 [M] ≤2 typefaces. 10 [J] pair fonts by contrast of role. 11 [M] tabular figures for aligning/updating numbers. 12 [M] right-align numeric table columns. 13 [J] don't fake secondary text with opacity on colored/imagery bg. 14 [M] don't center long text. 15 [M] no justified text on the web. 16 [M] real typographic characters (curly quotes, real …, nbsp between value+unit). 17 [M] all-caps only for short tracked labels. 18 [M] deliberate font-rendering + `font-display`. 19 [M] underline reserved for links. 20 [J] truncate only when the full value is recoverable.

**2. Spacing & layout** — 21 [M] fixed spacing scale (4/8/12/16/24/32…). 22 [J] start with too much whitespace, then remove. 23 [M] proximity encodes relationship (within < between groups). 24 [M] align to a few strong vertical edges. 25 [M] fluid between breakpoints, no magic widths. 26 [M] content determines width; don't stretch to fill. 27 [J] grids are a tool, not a religion. 28 [M] consistent gutters/page margins per breakpoint. 29 [M] respect safe areas/insets (`env(safe-area-inset-*)`). 30 [M] never horizontal page scroll (wide content scrolls in its own container). 31 [M] reserve space for async content (CLS≈0). 32 [J] optical adjustments over mathematical. 33 [M] consistent section spacing (vertical rhythm). 34 [J] one density per surface, applied throughout. 35 [J] design empty/short/overflowing states of every layout. 36 [J] ≤~2 levels of visual nesting.

**3. Color** — 37 [M] semantic tokens, never raw hex in components. 38 [J] restrained palette (one brand hue + grey ramp + few functional). 39 [M] define full ramps up front. 40 [J] no pure black/white for text. 41 [M] WCAG contrast: 4.5:1 body, 3:1 large/UI parts. 42 [M] never color as the only carrier of meaning. 43 [M] fixed semantic state palette (red=destructive, green=success, amber=warning, blue=info), off-limits for decoration. 44 [M] interactive states get visible color/contrast deltas (hover/active MORE contrast). 45 [J] disabled ≠ invisible (stay ≥~3:1). 46 [M] colored text on colored bg = same hue, adjusted lightness. 47 [J] large surfaces muted, small elements may be saturated. 48 [M] check under color-blind sim + greyscale. 49 [M] perceptually-uniform color math (OKLCH/APCA) for generated palettes.

**4. Visual hierarchy** — 50 [M] one primary action per view. 51 [J] de-emphasize to emphasize. 52 [M] three text emphasis levels are enough. 53 [M] labels de-emphasized, values emphasized. 54 [J] often drop the label when format makes meaning obvious. 55 [J] pass the five-second test. 56 [M] design for F/Z scan, front-load the left edge. 57 [M] visual weight matches importance (destructive quiet until confirm). 58 [J] semantics don't dictate visual size. 59 [M] group actions by meaning, platform-consistent placement. 60 [J] every screen answers where-am-I/what-changed/what-now.

**5. Elevation/shadows/borders/radii** — 61 [M] closed elevation scale, named tokens only. 62 [M] elevation maps to meaning (higher = closer/more temporary). 63 [M] layer shadows (ambient+direct), single light source. 64 [M] light-from-above consistent, never flips. 65 [J] not both strong border AND strong shadow on one element. 66 [J] borders are the last resort for separation. 67 [M] one radii system, nested radii computed (inner = outer − padding). 68 [J] radius is a brand-voice commitment. 69 [M] overlays get scrims.

**6. Iconography** — 70 [M] one icon family/weight/optical size. 71 [M] consistent grid + size-specific variants. 72 [J] icon-only only for universally-learned symbols. 73 [M] icon-only controls get accessible names + desktop tooltips. 74 [M] one-to-one icon↔concept mapping. 75 [M] align icons optically with text. 76 [M] filled-vs-outlined carries state, not whim. 77 [J] don't use icons as bullet decoration for prose.

**7. Imagery & illustration** — 78 [M] text over images needs scrim/overlay/treatment. 79 [J] one illustration + one photo style. 80 [M] never stretch/squash/auto-crop faces (`object-fit: cover`). 81 [M] UGC images get containment + defined bg. 82 [M] meaningful images get alt; decorative get `alt=""`. 83 [J] no low-quality/generic stock/AI filler. 84 [M] responsive images + reserved space. 85 [M] empty-state illustration is optional and must not replace the instructions.

**8. Data visualization** — 86 [M] chart type follows the question. 87 [M] bars start at zero; lines needn't but label the axis. 88 [M] honest axes (no dual-y tricks/uneven intervals/inverted). 89 [M] label data directly over legends where possible. 90 [M] maximize data-ink (kill gridlines/borders/3D). 91 [M] semantic, restrained chart color (≤6–8 categorical). 92 [M] chart colors survive color-blindness + greyscale (vary lightness). 93 [M] every chart states units/timeframe/context. 94 [M] tabular numerals + consistent precision. 95 [M] sort categorical bars by value unless order is inherent. 96 [J] big-number stats get comparison context. 97 [J] design empty/sparse/single-point chart states. 98 [M] the headline insight is visible with zero interaction. (See also the `dataviz` skill for palette/marks.)

**9. Motion** — 99 [J] every animation orients/connects/gives-feedback. 100 [M] UI transitions ~100–500ms (micro 100–200, standard 200–300, large 300–500). 101 [J] frequent-path animation never gates input. 102 [M] standard easing, never linear for spatial movement. 103 [M] animations interruptible + input-driven; avoid autoplay. 104 [M] honor `prefers-reduced-motion` with a reduced variant (fades, not nothing). 105 [M] enter/exit asymmetric. 106 [M] animate transform+opacity only, never layout props. 107 [M] never `transition: all`. 108 [J] shared spatial model (exit the way you entered). 109 [M] delay loaders ~150–300ms then persist ≥300–500ms. 110 [M] skeletons over spinners for content loads, matched to final layout. 111 [J] <100ms feedback needs no animation. 112 [M] no layout shift from motion. 113 [M] springs for gesture-driven, curves for triggered. 114 [J] limit concurrent motion (short stagger). 115 [M] continuous ambient animation is pausable + rare (WCAG 2.2.2).

**10. Dark mode** — 116 [J] full first-class theme, not an inversion. 117 [M] semantic tokens; components never branch on theme. 118 [J] dark surfaces are dark grey, not pure black (HIG contested). 119 [M] elevation = lighter surface in dark. 120 [M] desaturate accents for dark. 121 [M] contrast minimums apply; watch halation. 122 [J] dim/contain bright imagery in dark. 123 [M] set `color-scheme` + `theme-color` per theme. 124 [M] respect OS preference by default, manual override persists, no theme flash. 125 [M] charts get their own dark palette pass. 126 [J] shadows for shape, tints for depth in dark.

**11. UX writing & microcopy** — 127 [M] sentence case for UI text (Apple/Vercel Title-Case contested). 128 [M] CTAs verb-first + specific, never Submit/OK/Click here. 129 [M] front-load every string (first ~2 words carry meaning). 130 [J] cut word count ruthlessly. 131 [M] numerals not words for numbers. 132 [M] one term per concept everywhere. 133 [M] errors say what/why/what-next in human language. 134 [J] no "please" padding or alarmist words for routine errors. 135 [M] confirm dialogs name the object + consequence, buttons repeat the verb. 136 [M] empty states teach (what/why/what-to-do). 137 [M] placeholder is not a label. 138 [M] address the user as "you"; never mix my/your. 139 [M] active voice, present tense. 140 [M] links say where they go, no bare "Learn more". 141 [M] don't concatenate translated strings or bake plurals (ICU MessageFormat). 142 [M] leave room for localization expansion. 143 [M] locale formatters for numbers/dates/currency (`Intl.*`). 144 [J] relative timestamps for recency, absolute on demand. 145 [J] match the user's vocabulary, not the org chart. 146 [J] microcopy anticipates anxiety at commitment. 147 [J] success feedback brief and quiet. 148 [M] shortcuts/units/IDs render in distinct type.

**12. Content structure** — 149 [M] one h1, heading levels never skip. 150 [J] descriptive headings, not clever. 151 [M] lists/tables over prose for parallel content. 152 [M] one idea per paragraph, front-loaded. 153 [J] progressive disclosure for secondary content. 154 [M] explicit consistent truncation rules per content type. 155 [M] deliberate line-break/wrap (no number-unit breaks). 156 [J] first viewport states the page's purpose.

**13. Brand voice boundaries** — 157 [J] personality in content spaces; system UI stays neutral. 158 [M] voice drops all personality in error/payment/security/data-loss. 159 [M] voice defined once and versioned. 160 [J] humor survives repetition (recurring strings stay plainer). 161 [J] tone adapts to the moment, voice stays constant.

**14. i18n & RTL** — 162 [M] RTL = mirrored layout via logical properties, not a second stylesheet. 163 [M] mirror directional icons, never universal/media symbols. 164 [M] numbers/phone/LTR runs stay LTR inside RTL (bidi isolation). 165 [M] test RTL as a first-class layout state. 166 [J] translation completeness is a shipping gate per locale. 167 [M] leave room for script metrics + set `lang`. 168 [M] locale formats render from one shared formatting layer.
