# Engagement, data surfaces, media, help & self-service (canon 08)

Owning file: `docs/ux-canon/08-engagement-data-media-help.md` (191 principles). **[M]** mechanical, **[J]** judgment. Cite numbers (e.g. `// canon 08 §87`). The engagement ethics line throughout: the mechanic must serve the user's goal, not the app's engagement goal (§43, §44 regret test).

## Hard-rule digest

### A. Engagement & habit mechanics
**A1 Streaks** — 1 [J] attach a streak only to a behavior the user wants at their cadence. 2 [M] provide grace (freeze/repair/rest day), never all-or-nothing. 3 [M] prefer earn-back over pay-to-repair. 4 [J] apply grace automatically + silently when the reason is knowable. 5 [M] show streak state before the deadline, not only after loss. 6 [J] design the day-after-broken-streak screen with zero shame. 7 [M] count in the user's local timezone with a stated cutoff. 8 [J] long-cadence goals get long-cadence streaks. 9 [J] never make the streak the product's primary value.
**A2 Progress** — 10 [M] show progress to the next milestone, not just lifetime totals. 11 [J] never an empty bar — grant earned (honest) starting progress. 12 [M] progress bars linear/monotonic/tied to real state. 13 [J] milestones on a stretching curve. 14 [J] levels/tiers confer meaning, not just a number. 15 [J] default frame = past-self comparison. 16 [M] never reset earned progress as punishment for absence.
**A3 Celebrations** — 17 [J] scale celebration to the achievement. 18 [M] celebrate immediately, in the flow. 19 [M] skippable + short. 20 [M] say specifically what was achieved, in the user's terms. 21 [M] cap celebration frequency per session. 22 [J] first-time completions are a distinct class. 23 [M] respect reduced-motion.
**A4 Goals** — 24 [M] users set their own targets with a recommended default. 25 [M] adjustable any time without penalty. 26 [J] proactively suggest lowering a chronically-missed goal. 27 [M] pause/abandon cleanly, keeping history. 28 [J] frame over recoverable windows (weekly) not fragile days. 29 [M] show done-so-far + what's-left-and-when.
**A5 Reminders** — 30 [J] tie to the user's stated intention, not re-engagement wishes. 31 [M] user picks time + days with defaults. 32 [M] cap at one per behavior per day, back off after non-response. 33 [M] offer snooze + per-category opt-down before opt-out. 34 [M] never guilt/shame/fake-pressure in copy. 35 [J] make the loop completable in a small unit. 36 [M] permission in context, after value, with a pre-prompt.
**A6 Social comparison** — 37 [M] leaderboards/peer comparison strictly opt-in. 38 [J] bucket among rough peers, never global. 39 [M] leave/hide a leaderboard without leaving the product; control visibility. 40 [J] celebrate others (kudos), not zero-sum framing.
**A7 Variable rewards / anti-manipulation** — 41 [J] variable reward only on top of a guaranteed base. 42 [M] never randomize real-value outcomes with hidden odds (loot boxes). 43 [J] user's goal = the mechanic's goal (not presence/opens). 44 [J] pass the regret test. 45 [M] never fabricate scarcity/urgency/social proof. 46 [J] design for graduation (need extrinsic motivators less over time).
**A8 Records & achievements** — 47 [M] detect + surface PRs automatically at the moment. 48 [M] always-accessible records page per category. 49 [J] achievements earnable by every user type. 50 [J] show locked achievements with criteria (except rare surprises). 51 [M] recalculate records honestly on edited/deleted data. 52 [M] never award achievements for spending money/watching ads.

### B. Data tables, lists, dashboards
**B1 Sorting** — 53 [M] show which column is sorted + direction, always. 54 [M] meaningful default sort, stated (recency for time-based). 55 [M] toggle by header tap, reverse on second; mobile shows a labeled sort control. 56 [M] sort by underlying value, not the displayed string.
**B2 Filtering** — 57 [M] active filters visible as removable chips + Clear All. 58 [M] show the result count, updated live ("Show 17 results"). 59 [M] filtered-to-zero names the cause + offers to relax. 60 [M] AND across categories, OR within one, unless stated. 61 [M] persist filter/sort context on drill-in-and-back. 62 [J] expose a few high-value filters, fold the tail into a panel. 63 [J] distinguish search from filter, let them combine.
**B3 Pagination** — 64 [M] default to Load More (lazy) for browse lists. 65 [J] infinite scroll only for leisure feeds. 66 [J] numbered pagination only for reference/lookup. 67 [M] restore scroll position on back. 68 [M] state position + extent ("Showing 40 of 213").
**B4 List item anatomy** — 69 [M] one primary line + subordinate metadata + one obvious tap target (whole row). 70 [M] front-load the differentiating info. 71 [M] consistent row height/structure; predictable truncation. 72 [J] visual anchors only when they encode info. 73 [M] group long lists under sticky date-bucket headers.
**B5 Sticky headers & row actions** — 74 [M] sticky column headers + frozen first column on horizontal scroll. 75 [M] every swipe/hover action has a visible discoverable equivalent. 76 [M] reserve swipe for 1–2 frequent actions; destructive behind full-swipe+confirm/undo. 77 [M] ≤2–3 inline row actions, rest in a consistently-ordered overflow menu.
**B6 Density & columns** — 78 [J] density options on desktop tables; one right density on mobile; persist. 79 [M] right-align numbers, tabular figures, unit once in the header; left-align text. 80 [M] hide/show + reorder columns on wide tables, with a default + reset. 81 [M] table scrolls within its own container, never forces page horizontal scroll.
**B7 Mobile tables** — 82 [M] transform wide tables (card-collapse / priority-columns / frozen-column scroll), never shrink. 83 [J] choose the strategy by task. 84 [J] priority fields chosen by user need, not column order.
**B8 Selection & bulk** — 85 [M] selection mode announces itself (count + contextual action bar); leaving is one tap. 86 [M] select-all with explicit scope (all-visible vs all-matching). 87 [M] bulk destructive gets a count-confirming dialog + undo where feasible. 88 [J] disable-with-explanation over hide for inapplicable bulk actions.
**B9 Dashboards** — 89 [J] overview-first (how am I doing at a glance), details follow. 90 [M] every dashboard number drills down. 91 [M] state the time period on every metric, one consistent default. 92 [J] limit to metrics that drive action. 93 [M] honest comparisons (shared baselines, unclipped axes, same period lengths). 94 [J] design the sparse-data dashboard state deliberately.
**B10 Stats** — 95 [M] pair every headline metric with a comparison delta, direction meaning not by color alone. 96 [J] sparklines where trajectory matters more than the instant value. 97 [M] round to decision-relevant precision (store precise, display rounded). 98 [M] units + "how is this calculated?" on demand for computed metrics. 99 [M] number count-up animations <~1s + respect reduced motion.

### C. Media
**C1 Photo capture/upload** — 100 [M] offer camera + gallery in one native chooser. 101 [M] preview before commit (confirm/retake/cancel). 102 [M] determinate upload progress + cancel. 103 [M] on failure keep the local image + one-tap retry. 104 [M] state limits before selection, validate at pick time. 105 [M] respect/normalize EXIF orientation. 106 [M] compress/resize client-side when full res isn't needed. 107 [M] strip sensitive metadata (GPS/EXIF) on share + say so.
**C2 Image viewing** — 108 [M] meaningful user images open full-screen on tap. 109 [M] full-screen supports pinch/double-tap zoom + pan (web too). 110 [M] dismiss by swipe-down + tap-outside/X + Esc/back. 111 [M] swipe between images with a position indicator ("2 / 5"). 112 [M] progressive placeholders preserving layout space.
**C3 Cropping & avatars** — 113 [M] crop at upload with a live shape overlay. 114 [J] crop non-destructively where the original persists. 115 [M] decent default avatar (initials), never block flows on a photo. 116 [M] avatar change takes effect everywhere immediately + offers remove.
**C4 Video** — 117 [M] autoplay only muted, only where video is the content, instant override. 118 [M] standard controls (play/pause, scrub-with-preview, volume, fullscreen, captions, speed; keyboard). 119 [M] remember + resume playback position on longer video. 120 [M] captions for speech, default-on when muted-autoplay. 121 [M] short demo loops run controls-light but stay pausable (WCAG 2.2.2).
**C5 Audio** — 122 [M] audio continues in background + integrates with system media controls. 123 [M] respect audio-focus/ducking (pause for calls, duck other apps). 124 [M] persistent mini-player (scrub, ±skip, speed) for spoken content. 125 [M] never play sound on surface entry without a user gesture.
**C6 Galleries & carousels** — 126 [M] avoid auto-advancing carousels; if one exists it pauses on hover/touch/focus + never auto-advances on mobile (WCAG 2.2.2). 127 [M] show position + extent + both swipe and visible arrows. 128 [J] most important content in frame 1, ≤~5 frames. 129 [M] peek the next item to signal scrollability. 130 [M] grid↔viewer round-trips losslessly; user media manageable.

### D. Help & self-service
**D1 Contextual help** — 131 [M] never put task-required info only in a tooltip. 132 [M] unfamiliar/derived terms get an inline "what's this?" explainer. 133 [M] explain the "why" at the point of asking. 134 [M] contextual help short/task-phrased/dismissible; "Learn more" deep-links to the exact section. 135 [J] fix the design to be self-evident before adding help.
**D2 Progressive education** — 136 [M] teach in the moment of need, one thing at a time, no multi-step tour. 137 [M] coach marks one at a time/dismissible/never-repeat/never-block. 138 [J] learn-by-doing over learn-by-reading. 139 [M] make skipped education recoverable. 140 [J] announce new features in context, not a login-blocking modal.
**D3 Help centers/FAQs** — 141 [M] searchable + titles as user tasks/questions. 142 [M] articles structured for scanning (answer first, numbered steps with exact UI labels + current screenshots). 143 [M] help versioned with the product (no stale screenshots). 144 [J] cluster + cross-link related answers. 145 [J] FAQ only for genuinely asked questions.
**D4 Contact & support** — 146 [M] a visible findable path to a human, never a dead-end bot loop. 147 [M] set response expectations at submission + confirm receipt with a reference. 148 [M] pre-fill context (version/device/account/screen). 149 [J] channel choice by urgency; leave-and-return without losing the thread. 150 [M] escalation carries its context along.
**D5 Feedback & rating prompts** — 151 [M] ask only after a success moment, never mid-task. 152 [M] cap frequency hard; never re-ask soon after dismissal (~90 days for NPS-class). 153 [M] dismissible in one tap; "no" = not-now-for-a-long-time. 154 [M] never gate ratings (same door for everyone). 155 [J] keep in-app feedback low-effort + say what happens next. 156 [M] an always-available "Send feedback" door independent of prompts.
**D6 Release notes** — 157 [M] user-visible value in plain language, grouped New/Improved/Fixed (never eternal "bug fixes"). 158 [J] surface significant changes in-app once, non-blocking, + a browsable changelog. 159 [M] signpost moved/removed things at the old location.
**D7 Error self-service** — 160 [M] every error states what/why/next + links directly to that step. 161 [M] if the app can perform the fix, offer it as the primary action. 162 [M] escalate recurring errors to support with context; error codes searchable in help.

### E. Sharing & invites
**E1 Sharing off-platform** — 163 [M] use the native share sheet, don't rebuild it (copy-link fallback). 164 [M] the shared thing is a designed artifact, previewed before it leaves. 165 [M] share only what the user chose; private data never rides along. 166 [M] shared links state + honor permissions (who/what/revoke). 167 [M] "Copy link" confirms + the link works for its audience. 168 [M] shares are user-initiated one at a time; never auto-post. 169 [M] recipients land on a working web view first, app offer second.
**E2 Invites & referrals** — 170 [M] contacts never harvested; invites per-person, user-triggered, honestly attributed. 171 [M] referral rewards state full terms at the offer. 172 [M] the invitee's first experience honors the invite (deferred deep-link to the promised context). 173 [M] invite status visible to the sender without nagging the recipient.

### F. UGC safety, moderation, reviews
**F1 Report & block** — 174 [M] every UGC item + profile carries a reachable report affordance (App Store 1.2 requirement). 175 [M] reporting is a short structured flow with confirmation; reporter never exposed. 176 [M] block works completely + silently (two-way invisibility, no notification). 177 [M] content rules published in plain language, linked from composer + report. 178 [M] moderation closes the loop both sides (reporter outcome; author rule + appeal).
**F2 Profiles & community** — 179 [M] public-profile contents opt-in + previewable ("view as others"); private by default. 180 [M] comments follow the converged anatomy (author + time + content; labeled sort; shallow threading; self-delete; report/block per comment). 181 [M] community content attributed + dated. 182 [J] muting/feed control exist independent of blocking.
**F3 Ratings & reviews** — 183 [M] show average + total count + distribution, never a bare average. 184 [M] reviews sortable + filterable by star; negative as reachable as positive. 185 [M] each review carries evaluable context; "verified" only when actually verified. 186 [M] rating one tap, written review optional. 187 [M] never fabricate/seed/buy/selectively-solicit reviews; disclose incentivized ones.

### G. Downloads & export delivery
188 [M] descriptively named files (product-content-date). 189 [M] long exports follow the background-work contract (progress/cancel/completion notice carrying the file). 190 [M] delivery matches the platform (browser download desktop; share-sheet/save-to-Files mobile). 191 [M] after delivery say where it went + what it is.
