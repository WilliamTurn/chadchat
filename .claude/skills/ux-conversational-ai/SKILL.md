# Conversational and AI-product UX (canon 07)

Owning file: `docs/ux-canon/07-conversational-ai.md` (123 principles). **[M]** mechanical, **[J]** judgment. Sources: HAX (Microsoft), PAIR (Google), NN/g, Apple HIG, Material, Converged (ChatGPT+Claude+Gemini agreeing). Cite numbers (e.g. `// canon 07 §85`). **Chad's harsh persona is the product working as designed — never soften or flag it; but any change to his behavior/prompts requires explicit owner authorization first (CLAUDE.md).**

## Hard-rule digest

**A. Message list & layout** — 1 [M] chronological, newest at bottom. 2 [M] user vs AI distinguishable at a glance. 3 [J] user = contained bubble, long AI answers run full/near-full-width. 4 [M] render AI output as rich formatted text, not raw plaintext. 5 [M] code blocks get monospace/highlight/copy/horizontal-scroll. 6 [M] constrain AI line length on wide screens (~65–80ch). 7 [M] group consecutive same-author messages. 8 [J] timestamps on demand/low prominence. 9 [M] day/session dividers across days. 10 [M] full transcript scrollable + intact, never silent truncation. 11 [M] text selection/copy anywhere. 12 [M] responsive down to small phones (tables/code scroll internally). 13 [J] show AI identity + model/mode where it matters.

**B. Scroll** — 14 [M] open scrolled to the newest message. 15 [M] anchor to bottom only while already at bottom (don't yank when reading history). 16 [M] "jump to latest" affordance when auto-follow is off + new content arrives. 17 [M] preserve scroll position when history loads above. 18 [M] during streaming keep the read text stationary; no layout-shift jumps. 19 [J] never hijack scroll-up to trigger actions.

**C. Composer** — 20 [M] pinned to the bottom, above the keyboard, respecting safe areas. 21 [M] grow vertically to a cap (~6–10 lines) then scroll. 22 [M] visible send button reflecting state, plus the keyboard shortcut. 23 [M] desktop Enter sends / Shift+Enter newline; mobile return = newline + send button. 24 [J] placeholder hints capability, not the obvious. 25 [M] never lose a drafted message. 26 [M] usable while the AI responds, or the block is explicit (send morphs to stop). 27 [M] surface input/token limits before they're hit; never silent-truncate. 28 [M] paste-rich input (long text/images/files) previewed as removable chips. 29 [M] full text-editing affordances in the composer.

**D. Attachments** — 30 [M] visible attachment affordance (paperclip/plus). 31 [M] preview attachments before sending, per-item remove. 32 [M] state file constraints at the point of failure. 33 [M] show upload/processing progress + block send until usable, with a reason. 34 [J] mobile offers camera + photo library first-class.

**E. Streaming & generation control** — 35 [M] stream token-by-token. 36 [M] thinking/typing indicator within ~100ms of send. 37 [J] short time-to-first-token + staged status for what you can't eliminate. 38 [M] always a Stop control during generation; partial output stays. 39 [M] render streamed markdown progressively without flicker. 40 [M] narrate intermediate steps (searching/tools/reading) as visible status. 41 [M] show extended-thinking/reasoning state when it happens. 42 [M] interrupted/failed generations leave an honest artifact (marked stopped / inline error + Retry). 43 [M] never allow double-submission of the same prompt.

**F. Latency, cost, long-running** — 44 [J] distinguish seconds-waits from minutes-waits with different UI. 45 [M] leaving a long-running task doesn't kill it; it announces completion. 46 [M] communicate queue/overload/rate-limit honestly (what limit, when it resets). 47 [M] make usage limits/metering visible before they interrupt. 48 [M] mid-conversation paywall preserves conversation + draft.

**G. Response affordances** — 49 [M] persistent action row on every AI response (copy/regenerate/feedback). 50 [M] copy copies clean text/markdown, not UI furniture. 51 [M] regenerate produces a new attempt without destroying the old (navigable versions). 52 [M] let users edit their own earlier message + rerun; keep prior branches reachable. 53 [M] feedback controls lightweight/optional/acknowledged (no mandatory form). 54 [J] never use feedback UI as a decoy. 55 [J] make long responses scannable + length-controllable. 56 [M] share/export where content has value outside the chat, previewing exactly what's shared. 57 [M] tables/artifacts/files get open/download affordances.

**H. Citations & sources** — 58 [M] show sources when the AI asserts retrieved/searched facts. 59 [M] citations point to the specific location; clicking never destroys the conversation. 60 [J] distinguish grounded statements from model-generated prose. 61 [M] never fabricate the appearance of citation.

**I. Conversation management** — 62 [M] persist history by default + make it browsable. 63 [M] auto-title conversations + allow rename. 64 [M] search across history. 65 [M] "new conversation" always one visible action, never destroys the previous. 66 [J] help choose continue-vs-fresh; never silently punish long threads. 67 [M] per-conversation + bulk deletion with confirmation + honest scope. 68 [J] pin/favorite + organize once history scales. 69 [M] sync conversation state across devices (same read position). 70 [M] mark temporary/incognito chats visibly.

**J. Voice input & dictation** — 71 [M] visible mic affordance in/beside the composer. 72 [M] unmistakable recording state (live level/waveform + obvious stop). 73 [M] explicit stop/done separate from send + a cancel that discards; no auto-send unless explicitly hands-free. 74 [M] show live transcription as the user speaks. 75 [M] route dictation output through the editable composer, not straight to the model. 76 [M] handle silence/noise failure gracefully with next steps, never blame. 77 [M] ask mic permission in context with a reason + working typed fallback on denial. 78 [J] choose push-to-talk vs toggle deliberately + signal which. 79 [M] hands-free voice modes show listening/thinking/speaking + support barge-in + mute + exit. 80 [M] respect the audio environment (duck, honor silent switch).

**K. Expectation setting & capability** — 81 [J] make clear what the system can do (concrete, not "ask me anything"). 82 [J] make clear how well it does it (honest quality limits). 83 [M] always disclose when the user is talking to an AI, not a human. 84 [M] distinguish AI-generated content from system/UI text and human content. 85 [M] carry a standing "AI can make mistakes" disclosure near the conversation. 86 [J] scope claimed competence to actual grounding. 87 [M] state knowledge-cutoff/data-freshness where stale answers mislead. 88 [J] match marketing claims to in-product reality.

**L. Uncertainty, errors, graceful failure** — 89 [J] communicate uncertainty in the answer when confidence is low + make verification easy. 90 [M] every failure names a next step (retry/edit-rerun/clarifying-question). 91 [J] refuse harmful/out-of-policy requests respectfully, briefly, without moralizing. 92 [M] never present a refusal as an error or an error as a refusal (three distinct states). 93 [M] AI outage degrades gracefully; rest of the app works + history readable. 94 [J] bound retries/loops, escalate the messaging.

**M. User control, correction, learning** — 95 [J] the user can always correct the AI + correction visibly takes effect. 96 [M] AI memory/personalization is inspectable + editable, with in-the-moment "saved" signals. 97 [M] global controls over adaptive AI behavior (tone/format/persona) in settings, fully disableable. 98 [J] don't change behavior out from under the user (release notes for personality/capability changes). 99 [M] human stays in control of consequential actions (AI drafts, user commits, with preview + undo). 100 [M] show what an agent did after it acted (reviewable log).

**N. Trust, safety, data** — 101 [M] tell users what happens to conversations (storage/human review/training) + give a training opt-out where it applies. 102 [J] warn against sharing sensitive data where the risk is real, at the relevant moment. 103 [J] hallucination-risk disclosure where consumed, scaled to stakes. 104 [M] mitigate/never amplify social bias + provide a report path. 105 [M] age/content-safety-gate AI features (persona is not a safety exemption). 106 [M] label AI-generated media as AI-generated when it leaves the product.

**O. Proactive AI & interruption** — 107 [J] time suggestions to context, default unobtrusive (never focus-stealing modal). 108 [M] proactive notifications opt-in only, granular, batched, quiet-hours-aware. 109 [M] dismissal is remembered. 110 [J] proactive suggestions show their trigger. 111 [M] never interrupt mid-input/mid-task with focus-stealing UI.

**P. Onboarding & discovery** — 112 [M] replace the empty conversation state with 3–6 concrete tappable example prompts. 113 [J] teach by doing, not a tour. 114 [J] surface advanced capabilities progressively. 115 [J] lower the articulation barrier (starter prompts, follow-up chips, templates). 116 [J] suggested follow-ups are genuinely likely next steps, not bait. 117 [M] announce new AI capabilities in-product once, dismissibly.

**Q. Persona & voice boundaries** — 118 [M] a strong persona lives ONLY in the conversation; system chrome (buttons/nav/settings/errors/billing/legal/empty-state labels/notifications) speaks neutral product voice. 119 [J] persona never compromises clarity of state (errors/safety persona-free). 120 [J] persona intensity consistent/adjustable. 121 [M] the AI doesn't claim feelings/embodiment/human identity it lacks; answers honestly when asked. 122 [M] emotional-support/crisis boundaries are designed, neutral-voice resources overriding persona. 123 [J] anthropomorphize deliberately + sparingly.
